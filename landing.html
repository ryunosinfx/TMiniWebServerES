🖼️ ImageRoom
アプリ本体は GitHub Pages に公開済み。あなたが用意するのは、自宅 LAN の WebSocket 中継サーバーだけ。
クラウドにも外部サーバーにも写真を置かない、自分たちだけの写真共有ルーム。
サーバー1つ・設定QR1枚・はじめまで約5分

はじめ方は 3 ステップ

1

アプリを開く

GitHub Pages 上の img_room.html をブラウザで開くだけ。インストールもアカウントも不要です。

2

自宅 LAN にサーバーを起動

Raspberry Pi Pico W でも Node.js でもOK。WebSocket 中継（デフォルトポート 8080）を立ち上げるだけ。写真はどこにも上がりません。

3

接続を教える

アプリの「接続設定」でサーバーアドレスを指定（QR・リンクでも伝搬）。同じ LAN の人は誰でも部屋を作って参加できます。

何ができる？

🔒 クラウドゼロ

写真の保存先は参加者端末の内蔵ストレージ（OPFS/IndexedDB）だけ。LAN の中継サーバーはステートレスで、橋渡しした通信はすべて家庭内ネットワークの中で完結します（外部クラウドには一切上がりません）。

🖼️ サムネイルグリッド + カレンダー

部屋に入ると日付別の写真棚。日/週/月の切り替え、タグ絞り込み、10 万枚規模向けの縮小索引（ハッシュ重複は 1 ファイル）。

📴 オフラインでも見られる

既視の写真はキャッシュ済み。通信が切れても閲覧でき、再接続で自動同期。「（Websocketサーバーに接続不能）」の表示で原因も明確。

🔑 部屋パスワード + チャレンジ認証

平文パスワードはLANの中継を見ない限り流通しません。QR スキャンで即ログイン、作成者端末は電子署名で自己証明できます。

📦 一括 ZIP ダウンロード

部屋全体を分割 ZIP でダウンロード。ブラウザ拡張 imgroomCompanion を使えば毎日定時に自動取得・ハッシュ重複排除・7 世代バックアップまで無停止で回せます。

📱 スマホでも

レスポンシUI・一時退避（12h 経過で自動スキャン・退避）つき。LAN 内 http でもカメラ以外の主要機能は動作します。

システム構成

最短コマンド（Node.js の例）

git clone https://github.com/<あなたのユーザー名>/TMiniWebServerES.git
cd TMiniWebServerES
npm run server        # 0.0.0.0:8080 で静的配信 + WebSocket 中継が起動

GitHub Pages のアプリ（https）から接続するには、LAN 側に wss://（TLS）の終端を 1 行追加します。詳細と Raspberry Pi Pico W 版の手順は Setup.md にまとめています。

保存エリアと消し方（OPFS / IndexedDB / localStorage …）

ImageRoom はブラウザに内蔵の保存エリアだけを使い、Cookie と Service Worker は使いません。保存されるデータと、確実な消し方をまとめます。

保存エリア何を保存個別の消し方
OPFS（Origin Private File System）写真本体 bodies/<hash>・メタ meta/…jsonl・ゴミ箱 trash/・部屋定義 rooms/<rid>/room.json・作成者秘密鍵 keys/<rid>.json・作成者クレーム claim/<rid>.json・タグ tagreg/アプリ内: ゴミ箱で☓（完全削除）または「ゴミ箱を空にする」／トップページの部屋カード「削除」（keys・claim・索引も整理）。完全初期化は下の DevTools / サイトデータ削除
IndexedDBタグ検索補助の二次索引 imgroom_tagidx（失っても OPFS から再生成可能。写真自体は無し）ブラウザのサイトデータ削除で一緒に消える。DevTools → IndexedDB → 右クリック Delete で単独削除可
localStorage接続設定（WebSocket アドレス）・言語・参加日時・ゴミ箱掃除の日付・一時退避の暗号文（12h 超の自動スキャン時にだけ一時的に発生）サイトデータ削除で消える（設定は最初に戻る）
sessionStorage一時退避の復鍵（タブ専用。タブを閉じれば消滅）タブを閉じるだけで消える
メモリのみサムネイル・画像復号の一時バイトページを閉じれば自動消滅
確実な全消去（この端末から ImageRoom のデータを消す）
  1. ブラウザ設定から: サイトデータ削除（Chrome: 鍵/情報アイコン（URL 欄の左）→ サイトの設定 → このサイトデータの表示と削除 → 「削除」）。OPFS・IndexedDB・localStorage がまとめて消えます。
  2. DevTools から（正確）: F12 → Application → 左ツリーの Storage（このドメイン）→ 「ストレージを消去」（Clear site data）。各エリアの内訳は Storage Manager / IndexedDB / 「Origin Private File System」ノード で確認・個別削除できます。
  3. 特定の写真だけ: 部屋のサムネイル右上 ☓ でゴミ箱へ → ゴミ箱ビューで ☓（完全削除）。trash/ は既定 30 日で自動掃除（spec §9.8）。ゴミ箱から完全削除しても、同じ写真を他端末が持っていれば同期で復活します（コンテンツアドレス方式）。

※ GitHub Pages 版は <user>.github.io、LAN 直結版はサーバーの IP/ポートのオリジンが保存単位（異なるオリジンのデータは干渉しません）。秘密鍵ファイルはログイン画面右下「秘密鍵の移動（ダウンロード）」で退避してから消すと、後で別の端末へ引き継げます。
